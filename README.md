ARMLAB – Smart Patient Monitoring System

About the Project

ARMLAB is a smart patient monitoring web application designed to help medical teams monitor patient vital signs and review health-related alerts through a centralized dashboard.

Key Features

• Patient monitoring dashboard.
• Heart rate and skin temperature readings.
• GSR sensor data display.
• Reference range comparison.
• Automated alerts for readings outside reference ranges.
• Patient profiles and reading history.
• Alert review status management.

Technology Stack

• HTML
• CSS
• JavaScript
• Supabase Database

System Workflow

The system retrieves patient readings from Supabase and displays them through a web-based dashboard. Readings are compared with predefined reference ranges to highlight values that may require medical review.

Demo Notice

This project is a prototype developed for demonstration purposes. All patient information and readings are fictional sample data and are not real medical records. The system is not intended for clinical diagnosis or treatment decisions.
